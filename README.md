# Pi Config

## Prerequisites

- [`node`](https://nodejs.org/) 24+ and [`npm`](https://www.npmjs.com/) — packages and runtime
- [`pi-coding-agent`](https://www.npmjs.com/package/@earendil-works/pi-coding-agent) — harness
- [`git`](https://git-scm.com/) — bootstrap / package installs
- [`huggingface`](https://huggingface.co/docs/huggingface_hub/main/en/guides/cli) CLI with an auth token (see [auth config](./agent/auth.json))

## Setup

```bash
cd agent/npm && npm ci
```
